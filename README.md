# NEXUS Arcade

Mobile-first mini-game site for a college tech club fresher intro.

## Run locally

```bash
npm install
npm run dev
```

Then open the printed local URL on a phone on the same network, or scan nothing yet — share that URL / a QR of it at the event.

## Scripts

- `npm run dev` — Vite dev server (LAN host enabled)
- `npm run build` — production build
- `npm run preview` — preview the production build

## Games

- **Memory Match** — live, three difficulties
- **Find the Glitch** — live, 10 rounds with rising subtlety
- **Cipher Pulse** / **Signal Trace** — coming soon placeholders

No backend. Scores stay in the session.
